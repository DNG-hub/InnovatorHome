# InnovatorHome Pages Overview

This document provides an overview of the main pages in the InnovatorHome project.

## Index Page

The Index page (`Pages/Index.cshtml`) serves as the landing page for the application. It introduces visitors to Avanti AI Innovators and provides links to key sections of the site.

Key features:
- Displays a welcoming header about AI innovation
- Provides brief introductions to services, about us, and contact information
- Links to other main sections of the site

## What We Do Page

The What We Do page (`Pages/WhatWeDo.cshtml`) outlines the services offered by Avanti AI Innovators.

Key features:
- Introduces visitors to Avanti AI Innovators' services
- Describes various AI-related services and consulting offerings
- Uses a visually appealing layout with icons and sections for each service

## Consulting Page

The Consulting page (`Pages/Consulting.cshtml`) provides detailed information about the consulting services offered.

Key features:
- Outlines expertise in AI and Enterprise Content Management
- Describes the consulting process and approach
- Highlights key benefits of the consulting services

## AI Development Page

The AI Development page (`Pages/AIDevelopment.cshtml`) focuses on AI development strategies and offerings.

Key features:
- Introduces various AI development concepts and strategies
- Possibly includes case studies or examples of AI implementations
- Provides information on how Avanti AI Innovators approaches AI development projects

## Blog Page

The Blog page (`Pages/Blog/Blog.cshtml`) displays blog posts and categories. For more detailed information about the blog system, please refer to the [Blog System documentation](blog-system.md).

Key features:
- Lists recent blog posts
- Allows filtering by categories
- Displays full content of selected blog post
- Includes a sidebar with categories and recent posts

## Privacy Page

The Privacy page (`Pages/Privacy.cshtml`) outlines the privacy policy for the website.

Key features:
- Describes how user information is collected and used
- Outlines user rights regarding their data
- Provides contact information for privacy-related inquiries
